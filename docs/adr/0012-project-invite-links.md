# 0012. Приглашения в проект по одноразовой ссылке

## Контекст

Клиентов и участников проекта заводит админ. Нужен способ отдать доступ человеку,
который ещё не зарегистрирован, не пересылая ему пароль и не создавая аккаунт вручную.

## Решение

Админ создаёт приглашение в карточке проекта: роль (`manager`, `member`, `viewer`),
срок (1–30 дней) и, при необходимости, конкретный e-mail. Ссылка показывается один
раз; в БД хранится только `sha256` токена.

Публичная страница `/invite/{token}` показывает проект и роль. Приглашённый вводит
имя, e-mail, пароль и подтверждает два чекбокса: согласие на обработку ПДн и
ознакомление с политикой. После регистрации создаётся клиент, он добавляется в
`project_members` с ролью из приглашения, приглашение помечается использованным,
согласия пишутся в `consent_logs`, пользователь автоматически входит в CRM.

Ссылка одноразовая и истекает; занятый e-mail отклоняется; если e-mail задан в
приглашении, зарегистрироваться можно только с ним.

## Последствия

- Приглашение нельзя восстановить после закрытия страницы — админ создаёт новое.
- Письмо с приглашением не отправляется: ссылку передают вручную.
- Роль и срок фиксируются в момент создания; отозвать активное приглашение можно
  в панели проекта.
