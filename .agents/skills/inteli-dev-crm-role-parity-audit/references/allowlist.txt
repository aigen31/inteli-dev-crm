# Осознанные различия, которые не являются расхождением паритета.
# Формат: <область> | <исключение> | причина

admin | разделы clients/users/team/forms/settings | админские разделы не показываются обычному пользователю
executor | routes: tasks/reports/dashboard | узкие исполнительские маршруты для действий по назначенным задачам; те же разделы открываются через client.*
client | reviews (принятие/отклонение работы) | приёмку делает заказчик, исполнитель отправляет на проверку — разные действия, один каркас страницы
executor | reports (отправка отчёта) | отчёт клиенту отправляет исполнитель; у заказчика отчёт только читается
