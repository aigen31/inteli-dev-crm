# Audit 2026-11-13 — latest changes

## Findings

1. **Site kernel provider was stale.** Site MCP had 8 tools, but `/internal/assistant/profile` exposed only `site_lookup`. Fixed: profile now generates tools from `crate::mcp::TOOLS`; the tool endpoint dispatches all 8 read-only tools; `site_lookup` remains an alias.
2. **Kiki had no report tools.** CRM MCP could create reports, Kiki could not. Fixed: `create_report`, `list_reports`, `get_report` added to `CrmToolbox`; report creation requires confirmation.
3. **Kernel history could produce false 502.** Rolling history could start with an orphan `tool` message. Fixed in kernel: start at a user turn and keep only complete assistant/tool groups.
4. **Kernel truncated provider tools at 32.** Kiki had 36, so the last tools could be silently dropped. Fixed: `MAX_PROVIDER_TOOLS = 64`; a new audit check fails if a provider exceeds the limit.
5. **MCP protocol fallback was behind the site.** CRM fell back to `2024-11-05` while the site advertises `2025-06-18`; CRM fallback updated to `2025-06-18` (negotiated client version is still echoed).
6. **CRM surface diverged but largely intentional.** MCP has project/user/invoice/client reads and `crm_operation`; Kiki has assistant-only documents/plans/help and task budget/mass tools. Remaining decision: whether Kiki needs project creation/invites and client updates.
5. **Site MCP remains read-only.** Admin write API is not exposed to MCP; this is a security boundary, not drift.

## Re-audit after report and feedback management (2026-11-13, evening)

### Critical live finding — fixed

DeepSeek Harness still used the old local Node MCP server
(`mcp/src/server.mjs`, 20 tools) instead of the CRM's 30-tool streamable HTTP
endpoint. It was therefore missing projects, reports, users, forms, custom
field values, `crm_operation` and the other newer capabilities.

Fixed in the DSH web profile: the `crm` server now uses
`transport: streamable-http`, `https://crm.inteli-dev.ru/api/mcp`, and the
`MCP_TOKEN` bearer credential. The old `CRM_API_TOKEN` was removed from the
profile. Live verification after reload: `mcp__crm__list_projects` responds
successfully, so Harness has the 30-tool surface.

### Explicit UI-only decisions

The new admin operations are intentionally not exposed to MCP or Kiki:

- editing and deleting reports;
- editing feedback/bug records;
- archiving/restoring and rejecting feedback ideas and bugs.

These are moderation/administration actions. Keeping them UI-only avoids
letting an agent rewrite or silently archive already delivered reports and
public feedback; the existing MCP report creation/read tools remain available.

### Stale settings instructions removed

Admin Settings → API and MCP still advertised `CRM_API_URL` + `CRM_API_TOKEN`
and `node mcp/src/server.mjs` (the old 20-tool proxy). It now shows the
production HTTP MCP endpoint `POST /api/mcp` with `Authorization: Bearer <MCP_TOKEN>`
and links to `docs/mcp.md`.
