# Аудит поверхности инструментов — 2026-11-24

## Что менялось

- Завершение задачи больше не создаёт счёт: баланс списывается операцией
  `task_completed` (миграция удалила автосозданные счета).
- Календарь нагрузки: фильтр по дате в списках задач (админ, клиент,
  исполнитель) и в проекте; запоминание фильтров при навигации; единая
  палитра нагрузки.
- Пакетный редактор задач: тёмная тема шапки и предупреждения о статусах.
- Деплой: `scripts/deploy-prod.sh` + `docs/agents/deployment-prod.md`.

## Изменения поверхности

- `list_tasks` (MCP и Kiki) получил параметр `date` (YYYY-MM-DD) — задачи,
  которые занимают выбранный день. Это закрывает новую доменную операцию
  «показать задачи на дату» для внешних агентов и Кики.
- Новых tools нет; удалённых нет.
- Инвойс-инструменты (`list_invoices`, `get_invoice`, `create_invoice`,
  `mark_invoice_paid`) остаются: ручные счета и оплата прямых переводов
  никуда не делись. Автосчёт при завершении задачи не был отдельным tool,
  поэтому поверхность не меняется — изменилось только доменное поведение.
- Календарь нагрузки — UI-фильтр; отдельный tool не нужен, выборка задач
  доступна через `list_tasks` с `date`.
